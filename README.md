# Python Data Analyst

A structured collection of Python practice notebooks and learning
materials created while building practical **Data Analysis** skills.

## 📌 About This Repository

This repository contains hands-on Python exercises covering fundamental
programming concepts and practice topics. The goal is to build a strong
foundation for data analysis and gradually move toward real-world data
analytics projects.

## 🚀 Getting Started

### 1. Clone the repository

``` bash
git clone https://github.com/btit23see-droid/Python-Data-Analyst.git
```

### 2. Open the project

``` bash
cd Python-Data-Analyst
```

### 3. Start Jupyter Notebook

``` bash
jupyter notebook
```

Open any `.ipynb` file from the `Practice` folder and run the cells to
explore the exercises.
