# Python Data Analyst

A hands-on collection of Jupyter notebooks for learning **Python fundamentals** — starting from variables and data types, moving through operators, strings, and lists, and on to loops, user input, and practical mini-exercises. Built as a foundation for future data analysis work.

**Python · Jupyter Notebook**

## 📊 What You'll Learn

### Core Syntax (`Variables.ipynb`, `Data_Types.ipynb`, `Type_Casting.ipynb`)

- Declaring and assigning variables
- Python's built-in data types
- Converting values between types
- Understanding dynamic typing

### Operators (`Operators.ipynb`, `Operator_Precedence.ipynb`)

- Arithmetic, comparison, logical, and assignment operators
- Evaluating expressions with correct operator precedence
- Combining multiple operators in a single expression

### Strings (`Strings.ipynb`, `String_Concatenation.ipynb`, `Escape_Characters.ipynb`)

- Indexing and slicing strings
- Built-in string methods
- Concatenation with `+`, f-strings, and `.format()`
- Using escape characters like `\n` and `\t`

### Lists (`List.ipynb`)

- Creating and indexing lists
- Slicing and modifying list contents
- Common list methods

### Input & Output (`Print_Statement.ipynb`, `User_Input.ipynb`, `Comments.ipynb`)

- Formatting output with `print()`
- Capturing and using `input()`
- Writing clear single-line and multi-line comments

### Loops (`Loop/`)

- `for` loops and iterating over sequences
- `while` loops and loop conditions
- Nested loops
- `break` and `continue`

### Random Module (`Random_Module.ipynb`)

- Generating random numbers and choices
- Practical uses of the `random` module

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/btit23see-droid/Python-Data-Analyst.git
cd Python-Data-Analyst/Practice
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

**Windows:**

```bash
venv\Scripts\activate
```

**macOS / Linux:**

```bash
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Then start with:

```text
Variables.ipynb
```

And work through the notebooks in the suggested order above, finishing with the notebooks in `Loop/`.
